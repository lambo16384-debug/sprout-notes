讓 HTML 說清楚內容的角色

從一個簡單的筆記頁開始，認識語意標籤與標題階層，讓人與輔助工具都能理解你的內容。

#語意化#無障礙
TODAY’S LITTLE GOAL

讀完這篇，你可以…

能為筆記頁選擇 header、nav、main 與 article，並安排合理的標題階層。

01 / UNDERSTAND

先把觀念弄清楚

先問內容扮演什麼角色

header 放介紹資訊，nav 放主要導覽，main 是頁面的主要內容，article 適合可以獨立理解的文章。標籤描述的是內容角色，不是預設外觀；外觀交給 CSS。

用標題畫出文章大綱

本專案每頁使用一個 h1 作為主標題，各大段落用 h2，段落內的子主題用 h3。不要因為某個標題看起來比較小就跳過層級，應以 CSS 調整尺寸。

02 / EXPLORE

看一個小範例

htmlEXAMPLE
<header>我的學習筆記</header>
<nav aria-label="主要導覽">
  <a href="index.html">所有筆記</a>
</nav>
<main>
  <article>
    <h1>認識 HTML</h1>
    <h2>今天的學習目標</h2>
    <p>用標籤表達內容的角色。</p>
  </article>
</main>

main 集中主要內容，article 包住完整筆記，h1 與 h2 形成可理解的閱讀順序。

03 / TRY IT YOURSELF

換你動手試試

替一篇介紹 CSS 的筆記安排主標題，以及「概念」「範例」「練習」三個段落的標籤。

我想好了，看看參考解答

主標題用 h1，三個段落標題各用 h2，整篇包在 article 裡，再放進 main。文章中的說明用 p，不用連續的 br 代替段落。
