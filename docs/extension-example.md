# 實際延伸示範：第七篇響應式筆記

## 可重用的 AI 指令
> 請先閱讀 AGENTS.md、templates/note.json 與 css-grid.json。沿用既有版型新增一篇「響應式設計」入門筆記。slug 用 css-responsive，分類 CSS，order 7。必須有兩段核心概念、一段最小程式範例、練習、解答及 MDN 參考。不得手動改首頁卡片或複製文章 HTML。最後執行建置、測試及 Pages 同步，回報實際結果。

## 本次真正做了什麼
1. 先建立六篇筆記；建置產生 7 個 HTML，內容與站內連結檢查通過，5 項篩選測試通過。
2. 依既有 schema 新增 `content/notes/css-responsive.json`，沒有修改共用版型。
3. 重建後首頁自動成為七篇，CSS 分類數增加，新增文章與上下篇導覽自動生成。
4. 新頁沿用目標、概念、範例、練習、解答、參考的結構。

## 規則帶來的幫助
AGENTS.md 決定內容放哪裡、欄位如何填、頁面長什麼樣、哪些互動要維持、完成後怎麼驗證。AI 不需要猜資料格式，也不必逐頁手動更新導覽。新增主題主要是內容工作；樣式與導覽由同一個產生器維護。

這個示範適用於既有分類的新筆記。如果要新增分類、功能或改版型，仍需要同步調整驗證器、共用程式與測試。
